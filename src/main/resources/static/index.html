Insurance AI System

Welcome to the Insurance Policy Intelligence System. This system uses advanced AI and vector similarity search to answer queries about insurance documents.

Available API Endpoints:

POST /api/documents/upload - Upload insurance documents (PDFs are automatically chunked and embedded)
POST /answer/generate - Generate AI-powered answers using document-based retrieval (requires question and documentId)
POST /answer/vector-search - Generate AI-powered answers using vector similarity search (requires question only)
GET /answer/health - Check LLM service health and provider info
GET /answer/providers - List available LLM providers

System Features

Document Processing: PDF extraction, intelligent chunking, and embedding generation using all-minilm-l6-v2 model

Vector Search: Cosine similarity search to find the most relevant document chunks for any query

Retrieval Logging: Detailed logging of retrieved chunk IDs and distance scores for transparency

AI Answer Generation: Grounded answers using retrieved context from documents

Configuration

Prompts: Configured via src/main/resources/prompts.properties

LLM Provider: Set via llm.provider property in application.properties (default: openrouter)

OpenRouter API: Configure OPENROUTER_API_KEY environment variable or openrouter.api.key in application.properties

Model Selection: Choose from OpenRouter's model catalog (default: anthropic/claude-3-haiku)

This system provides intelligent document processing and question-answering capabilities for insurance policy documents using RAG (Retrieval-Augmented Generation).
