Insurance AI System

Welcome to the Insurance AI Document Processing System.

Available API Endpoints:

POST /api/documents/upload - Upload insurance documents
POST /answer/generate - Generate AI-powered answers (requires question and documentId)
GET /api/answer/health - Check LLM service health and provider info
GET /api/answer/providers - List available LLM providers

Configuration

Prompts: Configured via src/main/resources/prompts.properties

LLM Provider: Set via llm.provider property in application.properties (default: openrouter)

OpenRouter API: Configure OPENROUTER_API_KEY environment variable or openrouter.api.key in application.properties

Model Selection: Choose from OpenRouter's model catalog (default: anthropic/claude-3-haiku)

This system provides intelligent document processing capabilities for insurance documents.
